API Reference

Elysia HTTP + WebSocket server. Bun runtime. Redis backplane. Source: src/app/buildApp.ts.

GET /

Service root. Returns basic metadata and a link to the docs.

Response

{
  "service": "mock-trader-api",
  "status": "ok",
  "docs": "/docs/index.html",
  "websocket": "/ws/market"
}
GET /health

Lightweight process health. No dependency checks. Use /ready for deep verification.

Response

{
  "status": "ok",
  "service": "mock-trader-api"
}
GET /ready

Deep readiness check. Verifies Redis, subscription leases, Paytm session, and catalog count. Returns 503 when any check fails.

Response — 200 OK

{
  "ready": true,
  "checks": {
    "redis": true,
    "subscriptionLeases": true,
    "paytmSession": true,
    "catalog": true
  },
  "service": "mock-trader-api",
  "catalogCount": 12483,
  "catalogSyncedAt": "2026-06-28T18:00:00.000Z",
  "websocketPath": "/ws/market"
}

Response — 503 Service Unavailable

{
  "ready": false,
  "checks": {
    "redis": true,
    "subscriptionLeases": true,
    "paytmSession": false,
    "catalog": true
  },
  "service": "mock-trader-api",
  "catalogCount": 12483,
  "catalogSyncedAt": "2026-06-28T18:00:00.000Z",
  "websocketPath": "/ws/market"
}
FieldTypeSource
readybooleanAll checks pass.
checks.redisbooleanRedis PONG via store.ping().
checks.subscriptionLeasesbooleanLease repo PONG.
checks.paytmSessionbooleanhasPublicToken && hasReadToken.
checks.catalogbooleancatalogCount > 0.
catalogCountnumberLoaded instrument count.
catalogSyncedAtstring | nullISO 8601 of last sync.
websocketPathstring/ws/market.

GET /v1/market/instruments/:id

Resolve a single instrument by instrument key (NSE:EQUITY:3456), security ID (3456), or symbol (RELIANCE).

Response — 200 OK

Returns a single InstrumentRecord.

Response — 404

{
  "error": "instrument not found"
}
GET /v1/market/quotes

Return cached quotes for instruments. Stale quotes are refreshed through Paytm. Each result envelopes the instrument record, the quote payload (null if never seen), and a staleness flag.

Query parameters

ParamTypeDefault
idsstringComma-separated symbols, security IDs, or instrument keys.
mode"LTP" | "QUOTE" | "FULL"Defaults to UPSTREAM_PRICE_MODE env.

Response — 200

{
  "data": [
    {
      "instrument": { /* InstrumentRecord */ },
      "quote": { /* QuotePayload */ } | null,
      "stale": false
    }
  ]
}

Response — 400

{
  "error": "ids query parameter is required"
}

GET /v1/market/provider/chart

Raw Paytm chart proxy. Forwards arbitrary query params to /data/v1/price-charts/sym on the Paytm API. Response is pass-through from Paytm.

Response — 200

Raw Paytm JSON response (unstructured, pass-through).

Response — 400

{
  "error": "provider chart query parameters are required"
}

Response — 502

{
  "error": "provider chart request failed",
  "message": "Paytm request failed 401 ..."
}

Real-time quote fanout gateway. Configured via PRICE_WS_PATH env. Source: src/ws/marketGateway.ts.

{
  "type": "connected",
  "gatewayId": "uuid-string",
  "upstreamMode": "QUOTE",
  "maxSubscriptions": 100

QuoteEnvelope

Returned by /v1/market/quotes. Wraps instrument metadata, the latest quote, and staleness.

FieldType
instrumentInstrumentRecord
quoteQuotePayload | null
staleboolean

Staleness is determined by QUOTE_STALE_MS env (default 15s). quote is null if no quote has ever been received for this instrument.
